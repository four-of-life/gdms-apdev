DEV QUIZ FLASHCARD 

OVERVIEW

The Flashcard Learning Application is a digital educational tool designed to help students enhance their learning through question-and-answer flashcards.
The system enables users to create, organize, and review study materials efficiently using a structured and user-friendly interface.
The system aims to support active recall and repetition, helping students improve memory retention and academic performance.

PURPOSE
The purpose of this project is to create a functional and accessible study tool that assists students of Northern Bukidnon State College in organizing and reviewing their lessons more effectively.
It aims to:

Provide a digital alternative to traditional flashcards
Encourage independent and self-paced learning
Improve retention of information through repeated practice
Apply programming knowledge in Python and Java to a real-world educational system


How It Works (User)

1. Login / Start Screen
The user opens the application
The system displays a login or start screen
The user enters a username to begin

2. Select Difficulty Level
After entering a username, the user chooses a difficulty level:
The selected level determines the complexity or number of flashcards shown

3. Choose Avatar / Character
The user selects an avatar or character from a list of provided options

4. Start Flashcard Session
The system begins the quiz automatically
A flashcard is displayed on screen showing the question

5. Answer Input
The user types their answer into an input field
The user presses Enter to submit their response

6. Flip and Reveal Answer
After submission, the flashcard flips
The correct answer is displayed
Continue to Next CarD

8. End of Session

After finishing all flashcards:
The session ends
(Optional) The system may display results or score

How It Works (Admin)

1. Admin Login / Access Panel
The admin opens the application
The system displays the admin login screen

2. Dashboard Access

After logging in, the admin is directed to the dashboard
The dashboard shows system overview such as:
Total users, Available flashcard decks,System activity and performance summary

3. Manage Flashcards / Content
The admin can create, edit, and delete flashcards
Ensures questions and answers are correct and updated

4. Set Difficulty Levels

The admin assigns or configures difficulty levels:
Normal,Medium,Expert
Controls how many and how hard flashcards appear per level

5. Manage Avatars / Characters
The admin adds or updates available avatars,These avatars are used by users during login and sessions

6. Monitor User Activity and Performance
The admin can view user progress and results
Includes:Scores per session,Correct vs incorrect answers,Completion rate per deck

7. System Maintenance
The admin ensures the system runs smoothly,Updates flashcards, fixes errors, and manages stored data

8. Logout
The admin securely logs out after finishing system management tasks
